# Runtime Adapter Plan

`createIsolatedRuntimeAdapterPlan()` describes the adapter surface a future runtime WOULD
implement, as metadata only: `adapterKind: planned_metadata_only`, `adapterImplemented: false`,
and `reactAdapter` / `domAdapter` / `cssAdapter` / `routeAdapter` / `menuAdapter` /
`moduleAdapter` / `backendAdapter` all `false`. No adapter is implemented.
