# Visual Adapter Contract

Describes the adapter surface a future visual slice would implement to bind
render/layout/screen schemas to placeholder components. It is a description only:
`requiresReact`, `requiresDom`, `requiresCss`, `mountsAnything`, `importsComponent`,
`adapterImplemented` are all `false`. `downstreamSlice` points at
`ready_for_dev_preview_visual_contract_slice`.
