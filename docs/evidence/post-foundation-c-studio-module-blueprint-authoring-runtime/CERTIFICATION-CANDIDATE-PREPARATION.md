# Certification Candidate Preparation

`createCertificationCandidatePreparation({ draft })` prepares **candidate metadata** for a validated
draft. **Preparing a candidate is NOT certification.**

`candidateKind: blueprint_certification_candidate`, `candidateCreated` (only when validated),
`certified:false`, `canonical:false`, `registered:false`, `published:false`, `moduleGenerated:false`,
`requiresFutureExplicitSlice:true`, `requiresHumanCheckpoint:true`, `selfCertificationAllowed:false`.

No certifier exists; nothing is certified, published, registered, generated, or written to the SSOT.
