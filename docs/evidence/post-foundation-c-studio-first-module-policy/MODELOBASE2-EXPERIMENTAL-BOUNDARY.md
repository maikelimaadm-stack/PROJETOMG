# ModeloBase2 Experimental Boundary

## O que ModeloBase2 é

- Nasceu como **laboratório** para lançamentos operacionais futuros (headless, React-free no núcleo).
- É **experimental** — base de estudo sobre o generic-model kernel + operational runtime.

## O que ModeloBase2 NÃO é (por enquanto)

- **Não é módulo real.**
- **Não é produto final.**
- **Não substitui ModeloBase1.**
- **Não deve criar módulos oficiais agora.**
- **Não deve tocar backend/Prisma agora.**
- **Não deve registrar rotas produtivas agora.**
- **Não deve ir para o menu.**

## Permissões futuras

Pode futuramente servir de base para lançamentos operacionais como:

- lançamentos operacionais
- combustível
- pesagem
- apontamento
- checklist
- offline-first
- event log
- snapshot / restore

## Condições para avançar

O uso produtivo de ModeloBase2 só é liberado **depois** de todos os itens abaixo, e com decisão
explícita do mantenedor:

- **Studio Foundation**
- **Module Blueprint**
- **persistence decision** (política de persistência)
- **permission model** (modelo de permissões)
- **Registry controlado** (registro de módulo maduro)

Até lá, ModeloBase2 permanece **referência experimental**, sem qualquer efeito de produção.
