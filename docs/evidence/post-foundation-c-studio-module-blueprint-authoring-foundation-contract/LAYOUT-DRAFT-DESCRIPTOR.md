# Layout Draft Descriptor

`createLayoutDraftDescriptor(...)` — metadata only. No UI, component, DOM, or CSS.

Fields: `layoutId`, `layoutKind`, `sectionId`, `title`, `order`, `sections`, `slots`, `ordering`,
`visibilityDescriptors`, `fieldKeys`, `fieldCount`, `synthetic:true`, `canonical:false`,
`uiComponentCreated:false`, `domTouched:false`, `cssCreated:false`, `layoutDraftDigest`.
