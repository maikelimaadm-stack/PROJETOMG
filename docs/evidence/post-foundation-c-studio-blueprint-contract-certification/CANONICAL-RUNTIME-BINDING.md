# CANONICAL RUNTIME BINDING

`createStudioCanonicalRuntimeBinding()` certifica os bindings de referência.

## Mapeamento

cadastro → ModeloBase1 (referência inicial) · operacional → ModeloBase2 (apenas
experimental) · Empresas certified local read contract → seed model certificado +
**laboratório real/controlado** (não reescrito neste slice) · cadcps → Field Builder
reference · Generic Model Runtime → kernel.

## Regras

Empresas pode ser modificada futuramente **apenas em slice próprio** se tecnicamente
necessário. O binding não reescreve Empresas · não ativa produção · não registra
módulo · não acessa Prisma direto · não contorna tenant/permission.
