# Revision Engine Plan

`createRevisionEnginePlan()` plans deterministic, monotonic, in-memory revisions starting at 0.

`revisionEngineImplemented:false`, `revisionStartsAt:0`, `revisionMonotonic:true`,
`negativeRevisionAllowed:false`, `inPlaceCanonicalMutationAllowed:false`,
`historyPersistenceAllowed:false`, `inMemoryOnly:true`.
