# Synthetic Preview Handoff Plan

`createSyntheticPreviewHandoffPlan()` plans a future validated-draft handoff to the synthetic Preview
Sandbox only.

`handoffKind: synthetic_preview_candidate`, `compatibleWithPreviewSandbox:true`,
`previewHandoffImplemented:false`, `previewPayloadCreated:false`, `previewMounted:false`,
`realDataAttached:false`, `handoffToProduct:false`, `requiresValidatedDraft:true`.
