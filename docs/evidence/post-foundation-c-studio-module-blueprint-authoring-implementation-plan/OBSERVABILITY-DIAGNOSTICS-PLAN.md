# Observability / Diagnostics Plan

`createAuthoringObservabilityDiagnosticsPlan()` plans passive, sanitized, in-memory diagnostics for
the future runtime.

`passive:true`, `sanitized:true`, `inMemoryOnly:true`, `secretsLogged:false`,
`externalLoggingAllowed:false`, `telemetryRuntimeAllowed:false`, `realDataLogged:false`.
